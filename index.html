Frequently Asked Questions

Technical clarifications on permissions, storage, and file handling.

How does the dynamic aspect ratio engine calculate Midjourney parameters? +
The extension reads the naturalWidth and naturalHeight of the source image via HTMLImageElement APIs, simplifies the fraction using greatest common divisor heuristics, and appends the exact formatted parameter (such as --ar 16:9, --ar 9:16, or --ar 4:5) directly to the prompt parameter block.
How does the Screen Snip tool capture protected web images? +
The snip tool uses the browser tab capture canvas API to render a momentary freeze frame in memory. Users drag a bounding rectangle over the target area, extracting pixel data without needing access to obfuscated DOM source links.
Are visual files uploaded to external cloud APIs for processing? +
No. All canvas quantization, aspect ratio math, and parameter formatting execute within the local extension background service worker. No images are transmitted to external servers.
